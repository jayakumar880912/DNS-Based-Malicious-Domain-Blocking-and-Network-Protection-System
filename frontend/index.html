Core Security Architecture

Multi-Layered Network Protection

Enterprise DNS defense built to intercept advanced persistent threats before malware can execute payloads or contact command servers.

Real-Time DNS Sinkholing

Instantly intercepts queries directed at known malicious hosts and responds with a null route (0.0.0.0), neutralizing command and control callbacks.

AI Heuristics & DGA Detection

Analyzes domain lexical patterns and Shannon entropy to catch algorithmic domains (DGAs) and typosquatting scams before public blocklists index them.

Global Threat Intelligence

Synchronizes continuously with AlienVault OTX, URLhaus, AbuseIPDB, and OpenPhish feeds to maintain active immunity against emerging zero-day threats.

Ultra-Low Latency Engine

High-throughput in-memory DNS caching resolves queries in sub-15ms, ensuring robust network-level protection without dragging browsing speed down.

DoH & DoT Encryption

Supports DNS-over-HTTPS (DoH) and DNS-over-TLS (DoT) protocols, safeguarding DNS requests against ISP eavesdropping and man-in-the-middle attacks.

Forensic Audit Telemetry

Full visibility into every DNS query across the subnet with granular search, CSV exports, incident triage alerts, and automated security reports.

Resolution Lifecycle

How AegisDNS Protects Your Network

A seamless 4-stage pipeline that inspects every DNS lookup in milliseconds without requiring intrusive host agent software.

01

1. DNS Query Initiated

A workstation or device requests an IP address for an external domain name.

02

2. AegisDNS Interception

The query hits the local Aegis resolver on port 53 / DoH and is instantly matched against cached rules.

03

3. Threat Feed & Heuristics

The domain undergoes lexical analysis, DGA entropy testing, and threat feed cross-referencing.

04

4. Sinkhole or Resolve

Malicious queries are sinkholed to 0.0.0.0. Safe queries resolve cleanly in 14ms.

About The Project

DNS-Based Malicious Domain Blocking and Network Protection System

DNS is the foundational directory of internet communications. Cyber adversaries routinely exploit DNS for command-and-control beaconing, phishing landing pages, and ransomware key exchange.

AegisDNS addresses this critical attack vector by transforming the network's first line of inquiry into an active defensive shield. By blocking malicious domains at resolution time, client machines are prevented from ever establishing a TCP/IP handshake with threat actors.
